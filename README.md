**HealthSense** is a Java-based application designed for managing and analyzing healthcare data, specifically focusing on disease tracking and hospital information. The project emphasizes the use of fundamental data structures to handle complex management tasks.

### **Core Functionality**
*   **Disease & Outbreak Management**: Includes dedicated managers for outbreaks and reporting, utilizing a `Queue` for outbreak reports and a `Stack` for undoing actions.
*   **Data Organization**: Implements various organizational structures such as a Binary Search Tree (`BST.java`) and specialized lists for diseases and hospitals.
*   **System Analysis**: Features an `AnalysisManager` to process health data and generate insights.
*   **User Interface**: Contains a `Menu.java` and `InputManager.java` for handling console-based user interactions.

### **Technical Components**
*   **Language**: Java.
*   **Data Structures**: Binary Search Tree (BST), Queue, and Stack.
*   **Testing**: Includes a comprehensive `test` directory with JUnit tests for validating data models and management logic.
*   **Project Structure**: Follows a standard source/test directory layout and includes IntelliJ IDEA configuration files (`.idea/`, `.iml`).

**HealthSense** is a Java-based application designed for managing and analyzing healthcare data, specifically focusing on disease tracking and hospital information[cite: 2]. The project emphasizes the use of fundamental data structures to handle complex management tasks[cite: 2].

### **Core Functionality**
*   **Disease & Outbreak Management**: Includes dedicated managers for outbreaks and reporting, utilizing a `Queue` for outbreak reports and a `Stack` for undoing actions[cite: 2].
*   **Data Organization**: Implements various organizational structures such as a Binary Search Tree (`BST.java`) and specialized lists for diseases and hospitals[cite: 2].
*   **System Analysis**: Features an `AnalysisManager` to process health data and generate insights[cite: 2].
*   **User Interface**: Contains a `Menu.java` and `InputManager.java` for handling console-based user interactions[cite: 2].

### **Technical Components**
*   **Language**: Java[cite: 2].
*   **Data Structures**: Binary Search Tree (BST), Queue, and Stack[cite: 2].
*   **Testing**: Includes a comprehensive `test` directory with JUnit tests for validating data models and management logic[cite: 2].
*   **Project Structure**: Follows a standard source/test directory layout and includes IntelliJ IDEA configuration files (`.idea/`, `.iml`)[cite: 2].
